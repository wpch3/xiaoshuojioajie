## 一、不可变设定与写作底线

- **亲属关系**：卡莉亚是奥伦同父同母的亲姐姐；不能改成继姐、异母/异父姐妹或其他关系。
- **双重婚约**：奥伦与卡莉亚的既有婚约继续有效；奥伦与吉安娜的正式婚约也继续有效。两份婚约并存、不互相取代；不得擅自取消或改写。婚礼及成年后的选择按当前正文设定处理。
- **跨种族后宫与角色覆盖**：主角后宫规模要大；正式角色台账须覆盖全部原著种族与已有/新增原创种族，目标为每个种族至少有一位具名、有独立性格与剧情线的后宫成员。原著知名角色与原创具名角色均纳入角色池，不能靠无名路人凑数；按地图与时间线逐步登场，不做种族清单式收集。既有卡莉亚与吉安娜婚约继续有效、不互相取代。既有婚约按现有设定保留，不因角色年龄擅自取消；未成年阶段不描写成人性关系，正式亲密关系须在角色成年后依双方自主意愿发展。
- **主线设定**：奥伦的身份、能力、觉醒节奏，阿尔萨斯与莱安妮的既有设定，均以项目设定与用户明确要求为准；本大纲只组织地点、事件与节奏，不擅自改设定。
- **真龙能力锁**：交接材料明确奥伦的真龙本源与先天的“全知全能（解析一切）”“无限吸收与进化”能力；这些能力从早期就存在、可使用，不是后天职业技能，也没有被封印或等待解锁。后期才完整显现的是完整真龙形态、身份/称号与更宏大的呈现，不是能力从无到有。奥伦偏好凡人战斗方式是个人选择，不能写成无能力；关键处要让能力真实参与，但避免每场冲突都靠秒杀收场。
- **原创设定保留**：已有原创地图、种族、职业、元素及其他原创内容均纳入清点，不因版本目录重复或数量不一致擅自删减；同名、变体与版本差异要标注后再归并。
- **章节总量**：地图章节数是下限，不是目标上限。任何扩展都不能以删章、压缩地图或跳过地点来抵消。
- **地图串联不减配额**：跨图旅行、同一主线串联多张地图、地图交融叙事都只改变剧情顺序，不削减任何地图的1,000章下限。每章登记一个唯一的主地图计数归属；提及或短暂经过别图不重复计数，也不得借此把另一张图的配额压短。
- **单章规范**：约3,000—5,000汉字；保留场景小标题和章节末尾的小结、设定确认、写作反思/技巧、下章预告。章节写满依靠有因果的情节，不靠同一景物或对话重复填充。
- **叙事规范**：时间线连续；离队、归来、路程、季节变化要有交代；人物关系通过具体行动表现，避免模板化宣言；各地图必须有自身的地理、气候、资源、人口、历史与社会矛盾。
- **游戏式沉浸感**：写出探索路线、地图地标、任务线索、阵营/职业互动、补给与休整、发现与奖励、战斗准备和选择后果，让读者像在地图中行动；避免无理由瞬移、任务清单堆砌、掉落物清单化或重复刷怪。每段旅程都要有可感知的空间连续性和新的世界信息。
- **莱安妮病情**：按交接文档，诅咒治疗时机须服务于外部入侵危机，不能以瘟疫治愈线替代；目前第009—010章的寻药与魔法练习仍是进行中的情节，不能提前写成已治愈。

## 二、规模核算与地图单位（用户已确认）

原世界观文件写有 **11个大区、100个编号主地图/区域条目、500个子区域**。结构检查能找到100个主条目；子区域标题声称500项，但文件中可解析到498条显式子区域项目、479个不同名称；其中18个名称重复，共19条额外重复记录。它们是有用的发现清单，但既不是《魔兽世界》全部可游玩地图的最终目录，也不能简单把每个地点名都算作一张图。

### 已确认的独立地图计数口径

- **每个独立可游玩的《魔兽世界》原著地图各自计图**：包括所有开放世界区域，以及所有可游玩的地下城、团队副本、战场、场景/战役地图和其他独立地图类型。
- 原著不同版本或时间线若呈现为可独立进入、具有独立地图内容的地图版本，分别登记；同一地点的别名、同图内的城镇/地标/兴趣点不重复算图，除非它本身确实是独立可游玩的地图。
- **达拉然独立新增**，不能再仅作为晶歌森林或其他地图下的子地点处理；达拉然有自己的地图条目与章节配额。其最终地图编号待全量审计，不沿用M101作为最终号。
- 所有现有原创地图、用户提出的原创地图想法与原创故事地图均保留；每个独立地图也各自至少1,000章。
- 原著种族、职业，以及现有原创种族、职业、元素等全部纳入清点，不因目录差异删减。

### 章节配额与总量

每张独立地图至少1,000章，只能更多不能更少；多张地图可以由同一条旅行线、人物关系或主线串联，但任何串联、融合、交错都不能减少各图的章节下限。全量地图清单尚未建完，因此**最终地图数与全书最低章数暂不写死**。旧草案中“100条主条目+达拉然=101,000章”的算法已被新的地图单位取代，不能当作最终总量或完整规模估计；完成所有可游玩地图盘点后再逐图相加。

**计数规则**：每章登记一个唯一的主地图；其余地图可以作为支线、远程影响或行程接口出现，但不得重复计数。跨图章节顺序可以交错，每张地图本地章节仍分别累计到至少1,000章。地图章节统一使用待审计后的独立地图编号与本地章号；全书顺序号另行编排。

### 情节丰富度与不重复原则

用户确认每张图可以先集中写一个完整事件，也可以并行或交织战斗、外族/种族冲突、政治权斗、日常生活、贸易、探索、职业技艺、关系变化和善后重建等线索。组合方式依地图文化、历史、势力与事件决定，不要求每一章面面俱到，也不得把每张图复制成相同的“遇袭—获胜—告别”模板。每张图的事件类型、节奏和人物视角要有变化，确保故事耐看、不腻。

## 五、每张地图的1,000章结构骨架

以下是**编排框架，不是让所有地图套用同一批情节**。每图都拆成至少10个各100章的阶段；每个阶段再按10章一个小单元规划。具体事件必须从该图的地点、资源、居民、历史和势力中生长出来，不能只替换地名重复同一套“遇袭—获胜—告别”。

| 本地图章号 | 阶段功能 | 必须形成的变化 |
|---|---|---|
| L0001—L0100 | 入图与落脚：路线、气候、聚落、日常秩序、主要人物 | 主角理解当地生活，不只完成观光；确立本图第一项可验证的问题 |
| L0101—L0200 | 地方生活与资源：粮食、贸易、交通、工艺、民生 | 让本地图的经济与地理进入实际冲突；出现持续数十章的本地关系网 |
| L0201—L0300 | 历史与制度：家族、领主、传统、旧约、边界 | 揭示历史如何影响眼下利益；建立多方立场，避免单一“好人/坏人” |
| L0301—L0400 | 分区探索：村镇、道路、地标、遗迹或特殊生态 | 每个子地点带来新信息/新代价；探索结果改变下一段行程 |
| L0401—L0500 | 局部矛盾升级：资源、治安、贸易或势力冲突 | 让前期线索交汇；角色需要选择而非靠全知能力直接跳过过程 |
| L0501—L0600 | 深层秘密与能力考验 | 解释本地异常的来历或限制；能力使用带来成本、责任或关系后果 |
| L0601—L0700 | 结盟与分歧：谈判、调查、同行者选择 | 合作必须有条件；联盟内部也有利益差异和可追责的承诺 |
| L0701—L0800 | 地图级主冲突 | 主要问题达到高点，靠前期准备与各方行动解决，不凭空降神 |
| L0801—L0900 | 善后与重建 | 写清受影响地区、普通人的恢复、利益重新分配以及角色变化 |
| L0901—L1000+ | 本图收束与下一图接口 | 本图的核心问题有阶段性结果；留下有因果的下一地图动机。若地图仍有未完成地点/人物线，继续增加，不得硬切到下一图 |

**每10章最低检查项**：本单元目标、阻力、地图特征、人物选择、结果/代价、对下一单元的影响至少各有明确落点。每张图可以围绕一个事件深写，也可把战斗、种族/外族冲突、政治权斗、日常、贸易、探索、职业技艺与善后等线索交织；由地图本身决定组合和节奏，避免章节流水线。可以有日常章，但日常要承接人物关系、资源、制度或主线，不用重复吃饭/散步/赞美来填数。

## 七、当前正文的处置建议：先优化，再决定是否插入新章

1. **不为重复内容增加整章**：先清理倒序、重复和重复出发/到达场景。若一个章节的结构问题严重，按写作指南整章重写，保留原有设定与有效情节，不用一句补丁掩盖。
2. **保留每一个已写章节槽位**：改写、拆分场景、调整章内顺序都不等于删章；不得把已有章节数量压低。只有出现必要的时间桥、旅行段或因果缺口，才额外插入新章，章数只增不减。
3. **第001—010章先按当前正文锁定事实**：第一轮已修订并去重，统一按整份Markdown的CJK汉字字符数统计，十章均达到约3,000—5,000汉字下限；该数包含标题、小结与设定确认，后续仍以正文质量审读为准。继续修订时保持有因果的行动、选择与后果，避免为凑字数堆砌；同时按地图级细纲推进，防止与远期路线冲突。
4. **地图描写不等于风景堆砌**：每次进入一个地点，至少让地形/天气/资源/交通/居民生活中的一项改变角色的决定，并在后文留下影响。
5. **结尾检查**：每章后标记时间、地点、人物所在、未解决问题、已知设定、下一章承接点；每个100章阶段完成一次地图台账复核。
