# 种族与后宫角色覆盖台账（工作版）

> **用途**：把跨种族的大型后宫与原著/原创角色要求落成逐项核对表，避免遗漏、重复计数或把人物当名单。此表先保留原始设定中的100个编号条目；它们尚未全部核实为互不重复的生物学种族，也不是最终的《魔兽世界》种族总表。
>
> **源材料核对提醒**：`世界观设定-真龙的艾泽拉斯.md`称有“100个主要种族、300个进化方向”，但七类标题所标数目相加为110，编号条目又存在重复/变体，且有的条目实际是职业、元素类别或机械形态。故本台账先保留所有原始条目，不把重名项静默删除，也不把它们未经审计地宣称为100个不同种族。后续需与原著可玩/非可玩种族、全部原创种族、进化分支和其它设定文件交叉核对。

## 一、已锁定的覆盖要求

- 主角后宫规模要大，最终角色规划必须覆盖**每一个经审计确认的原著种族与原创种族**；每族至少有一位具名、有独立性格、关系发展和完整剧情作用的后宫成员。种族变体/分支按审计结果记录，不因整理而漏掉。
- 原著知名角色与原创具名角色都进入角色池；人物要分阶段、分地图自然登场，不做“每章/每图收一个”的打卡清单。每个人都应参与本族社会、地图主线或人物关系中的具体事件。
- 只把实际建立的成员关系标为“完成覆盖”；候选名字、短暂同盟、单向好感、擦肩而过都不算完成。每名成员保有主体性、个人目标与自愿选择。
- 既有奥伦—卡莉亚、奥伦—吉安娜两份婚约继续保留、并存，不能互相取代。卡莉亚是奥伦同父同母的亲姐姐；角色关系照用户锁定设定登记，不得擅自改写。成人亲密内容不落在未成年时间段。
- 角色池不以“可攻略”为借口删减原著人物或原创种族；反派、敌对势力及其成员也先按种族/角色登记，再根据时间线、人物塑造和双方选择决定关系发展，不能强迫转化为恋爱线。

## 六、完成判定

1. 先从原始文件和原著资料中建立不漏项的正式种族清册，并为“种族、亚种/文化、进化形态、职业、元素类型”划清边界；原始编号的每项都需有去向。
2. 为每个正式种族至少安排一名具名后宫成员；若一族包含多个用户明确要求单独覆盖的独立族群/分支，再分别建行，不靠笼统的“代表角色”带过。
3. 原著知名角色与原创角色均要在总角色池中有明确位置；不能只列姓名，需有可追踪的首次登场、独立剧情线和关系进展。
4. 每张地图至少1,000章的配额与后宫覆盖任务并行，不以角色初次出现、短暂同行或跨图旅行抵扣任何地图章节。
5. 角色过多时以分期登场、并行关系和群像叙事承载；绝不通过删种族、删原创角色、弱化人物主体性或机械收集来“解决”规模问题。
